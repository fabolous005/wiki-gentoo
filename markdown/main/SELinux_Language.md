# SELinux/Language

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

SELinux has a very extensive language in which policies and SELinux enforcement behavior can be defined and controlled.

## Resources

- [Official SELinux project wiki](http://selinuxproject.org/page/Main_Page) which contains detailed information about SELinux policy statements
- [SELinux Notebook](https://github.com/SELinuxProject/selinux-notebook/), an *excellent* resource for SELinux policy language and constructs. Originally created by Richard Haines who graciously donated the source material to the SELinuxProject, now maintained by the SELinux community.
