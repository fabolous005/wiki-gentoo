# rc

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)


rc is an ancient Plan 9 abbreviation that stands for **r**un **c**ommands. Eric Raymond's The Jargon File mentions a script of a similar name called rc file. This file contained "startup instructions for an application program (or an entire operating system)".[\[1\]](https://wiki.gentoo.org#cite_note-1)

It would seem rc was the basis for modern [init systems](https://wiki.gentoo.org/wiki/Init_system).
