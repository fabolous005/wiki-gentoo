# F3

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

F3 (**F**ight **F**lash **F**raud, or **F**ight **F**ake **F**lash) is an open source, cross platform H2testw clone. It fights fraud by creating a series of files to readable portions of flash memory and does calculations on current read/write speed. It can be useful in determining how much usable storage is actually present on a a device, despite what is on the devices label.

## Installation

### USE flags


### USE flags for
            [sys-block/f3](https://packages.gentoo.org/packages/sys-block/f3)
            
            Utilities to detect broken or counterfeit flash storage

| [extra](https://packages.gentoo.org/useflags/extra) | Build the additional f3probe, f3brew and f3fix utility (requires sys-block/parted and virtual/udev) | 

### Emerge

`root #``emerge --ask sys-block/f3`
## Usage

### Test device is valid

To probe a block device for counterfeit flash memory use f3probe utility. In case of faked size resulting output will show command to fix your device, something like this:

`root #``f3probe --time-ops /dev/sde````

### Test write speeds

In order to do a true read test, F3 must first create a series of .hw2 files in the available free space on the device:

`root #``f3write /path/to/mountpoint`
Depending on the size, free space, and write speed of the device, his could take quite a while. Whenever it is finished, it will be possible to test read speeds.

### Test read speeds

After the write test has finished, read speed can be tested using the following command:

`root #``f3read /path/to/mountpoint`
F3 will read though the available .hw2 files and calculate if there are any consistency errors. It will also calculate read speed. It is quite normal for read speed to be faster than write speed, especially on removable media.

## Removal

### Unmerge

`root #``emerge --ask --depclean --verbose sys-block/f3`
