# Wikibot

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

![](https://wiki.gentoo.org/images/thumb/8/8e/Wikibot-screencap.png/300px-Wikibot-screencap.png)

The Gentoo **wikibot** it a bot that sits in [#gentoo-wiki-changes](ircs://irc.libera.chat/#gentoo-wiki-changes) ([webchat](https://web.libera.chat/#gentoo-wiki-changes)) to report changes to users of the channel, in near real time.

## Configuration

[UTF-8](https://wiki.gentoo.org/wiki/UTF-8) (unicode) support is required for the bot output to display correctly. A font that supports UTF-8 "[emoji](https://en.wikipedia.org/wiki/emoji#In_Unicode)" characters, such as [media-fonts/noto-emoji](https://packages.gentoo.org/packages/media-fonts/noto-emoji), may also be required.

## Usage

The bot does not support any commands currently.
