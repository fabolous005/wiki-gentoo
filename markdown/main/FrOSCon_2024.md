### Project Room

As discussed at the FrOSCon 2023, we applied for a shared project room of [Gentoo e.V.](https://gentoo-ev.org/) and the [TroLUG](https://trolug.de/). 
In the project room we can help to install Gentoo, discuss/repair ebuilds and provide mugs, buttons and shirts.

Contact vorstand at gentoo-ev.org if you want to join the booth.
