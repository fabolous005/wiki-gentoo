# M68k

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The **m68k** architecture is supported within Gentoo through the [Gentoo m68k Project](https://wiki.gentoo.org/wiki/Project:M68k).

### Supported Stages

Currently Gentoo supports four stage3 tarballs:

- OpenRC with Glibc
- OpenRC with Musl
- Systemd with or without mergeusr

All stages can found [here](http://distfiles.gentoo.org/releases/m68k/autobuilds/).
