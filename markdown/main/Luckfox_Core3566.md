# Luckfox Core3566

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The **Luckfox Core3566** is a development board compatible with the [Raspberry Pi CM4](https://www.raspberrypi.com/products/compute-module-4).

Follow [https://github.com/Necktwi/core3566](https://github.com/Necktwi/core3566)

Reading the scripts will help in understanding the build process!

Build scripts in the above git repo can b easily modified to build n flash Gentoo to any SBC.
