# QEMU/Guest/Windows 11

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Libvirt Windows 11 guest details the creation and handling of Windows 11 guest virtual machine on QEMU host.

## Overview

Windows 11 guest uses modern virtual hardware under libvirt with QEMU/KVM. UEFI firmware (OVMF) is required. VirtIO storage and network devices are recommended. TPM 2.0 device is required.

Windows 11 guest is defined through libvirt domain XML generated by [virt-manager](https://wiki.gentoo.org/wiki/Virt-manager), [virsh create](https://wiki.gentoo.org/wiki/Virsh#Create_domain) domain, or [virt-install](https://wiki.gentoo.org/wiki/Virt-install).

This page demonstrates a workflow using virt-install to generate the domain XML, followed by virsh for lifecycle control.

## Requirements

Verify that required components are installed and ready:

- QEMU with KVM support ([QEMU install](https://wiki.gentoo.org/wiki/QEMU#Installation))
- libvirtd daemon and virsh ([libvirt install](https://wiki.gentoo.org/wiki/Libvirt#Installation))
- virt-install ([virt-install](https://wiki.gentoo.org/wiki/Virt-install#Installation))
- UEFI firmware (OVMF) ([UEFI support](https://wiki.gentoo.org/wiki/QEMU#UEFI_support))
- swtpm for [TPM](https://wiki.gentoo.org/wiki/Trusted_Platform_Module) 2.0 ([TPM support](https://wiki.gentoo.org/wiki/QEMU#TPM_emulation))
- Windows 11 installation ISO
- VirtIO driver ISO (v1.190 or later)

## Installation process

This installation process uses qemu-img and virt-install to define a libvirt [domain](https://wiki.gentoo.org/wiki/Libvirt/domain).

Stages:

- Disk image creation
- Domain definition (virt-install
- Guest installation
- Driver installation (VirtIO)

### Parameters

Define the parameters for Windows 11 guest to be 40GB hard drive, 4GB memory, 'default' networking, and 2 CPU.

`user $``bash`
DOMAIN\_NAME="windows-11"
RAM\_SIZE\_MB=4096
VCPU\_COUNT=2
OS\_ISO\_PATH="/iso/win11.iso"
VIRTIO\_ISO\_PATH="/iso/virtio-win.iso"
DISK\_IMAGE\_SIZE=40G
DISK\_IMAGE\_PATH="/var/lib/libvirt/images/win11.qcow2"
NETWORK\_PROFILE="default"

### Virtual disk creation

Create disk image:

`root #``qemu-img create -f qcow2 $DISK_IMAGE_PATH $DISK_IMAGE_SIZE`
Set ownership and permissions:

`root #````
chown qemu:qemu $DISK_IMAGE_PATH
```
`root #````
chmod 600 $DISK_IMAGE_PATH
```
### Domain creation

virt-install generates and defines the domain.

`host$````
virt-install \
```
--name $DOMAIN_NAME \
 --os-variant win11 \
 --machine q35 \
 --cpu host \
 --vcpus $VCPU_COUNT \
 --memory $RAM_SIZE_MB \
 --boot loader=/usr/share/OVMF/OVMF_CODE.fd,loader.readonly=yes,loader.type=pflash,nvram.template=/usr/share/OVMF/OVMF_VARS.fd \
 --disk path=$DISK_IMAGE_PATH,bus=virtio \
 --disk $VIRTIO_ISO_PATH,device=cdrom \
 --cdrom $OS_ISO_PATH \
 --network network=$NETWORK_PROFILE,model=virtio \
 --graphics spice \
 --video qxl \
 --tpm backend.type=emulator,backend.version=2.0,model=tpm-tis \
 --noautoconsole

virt-install performs:

- XML generation
- libvirt domain definition
- optional domain start

### Verification

#### XML validation

Dump XML:

`host$``virsh dumpxml windows-11 > windows-11.xml`
Validate XML:

`host$``virt-xml-validate windows-11.xml`
Validate host:

`host$``virt-host-validate qemu`
Translate to QEMU:

`host$``virsh domxml-to-native qemu-argv windows-11.xml`
## VirtIO Driver installation

Load VirtIO drivers during installation:

- Select disk driver (viostor)
- Select network driver (virtio-net, NetKVM)

Drivers are located on attached VirtIO ISO.

## Domain management

List domains:

`host$``virsh list --all`
Start domain:

`host$``virsh start $DOMAIN_NAME`
Display console:

`host$``virsh vncdisplay $DOMAIN_NAME`
Shutdown domain:

`host$``virsh shutdown windows-11`
Force stop:

`host$``virsh destroy windows-11`
## Removal

Remove domain:

`host$``virsh undefine windows-11`
Remove disk:

`host$``rm /var/lib/libvirt/images/win11.qcow2`
## Troubleshooting

### TPM missing

Windows installer reports missing [TPM](https://wiki.gentoo.org/wiki/Trusted_Platform_Module).

Ensure swtpm is installed and TPM device is defined:

- [app-crypt/swtpm](https://packages.gentoo.org/packages/app-crypt/swtpm) (package providing daemon and tools)
- swtpm-tools (utilities for TPM state management, also app-crypt/swtpm package but with USE+="libvirt socket tools")
- libvirt TPM driver support

### Secure Boot issues

Windows installer fails boot.

Verify correct OVMF firmware paths and variables file.

### No network

Windows 11 domain has no connectivity and cannot access network resources.

List the available network profiles:

`host$``virsh net-list --all`
If 'default' is not listed, repair it using:

`host$``virsh net-start default``host$``virsh net-autostart default`
Quick check if the KVM module is installed:

`root #``lsmod | grep kvm`
If 'kvm' does not appear, then KVM module is not loaded or is missing.

Load required modules:

`root #``modprobe kvm`
If on x86, x64, i686, i386 (Intel):

`root #``modprobe kvm_intel`
If on AMD64 platform:

`root #``modprobe kvm_amd`
