# Live environment

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

A live environment is a term that describes an ephemeral or disposable operating system environment, typically created from a [live image](https://wiki.gentoo.org/wiki/Live_image).

## See also

- [Live image](https://wiki.gentoo.org/wiki/Live_image) — an operating system (OS) environment contained within a file that can be used to [boot](https://en.wikipedia.org/wiki/Booting) a system
