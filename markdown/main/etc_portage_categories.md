# /etc/portage/categories

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/etc/portage/categories** is a file that contains a simple list of valid categories that may be used in repositories and the `PKGDIR` variable. The existence of a categories allows for custom package categories to be created. Custom overlays may define profiles/categories relative to their overlay root.

## Format

- One package category per line.
