# UB500

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The **UB500** or **UB500 Plus** (2357:0604) are a small bluetooth adapters produced by TP-Link.

![](https://wiki.gentoo.org/images/thumb/6/6e/Ub500-angle.jpg/300px-Ub500-angle.jpg)

![](https://wiki.gentoo.org/images/thumb/e/ee/Ub500_plus.jpg/300px-Ub500_plus.jpg)

## Configuration

Chipset: **Realtek RTL8761B**, so the following needs to be enabled for [sys-kernel/linux-firmware](https://packages.gentoo.org/packages/sys-kernel/linux-firmware):

FILE **`/etc/portage/savedconfig/sys-kernel/linux-firmware`**

For instructions on use, see [Device pairing](https://wiki.gentoo.org/wiki/Bluetooth#Device_pairing).
