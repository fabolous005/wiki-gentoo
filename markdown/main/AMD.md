# AMD

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Advanced Micro Devices, Inc. (AMD)** is a semiconductor company. AMD is best known for producing CPUs based on [x86 intruction set](https://en.wikipedia.org/wiki/x86), motherboard chipsets and their own line of GPUs. Later AMD created [amd64](https://wiki.gentoo.org/wiki/AMD64), which is the 64-bit equivalent instruction set of the x86.

## Available software and articles

From Gentoo standpoint this wiki covers the following AMD related articles among others:

### Graphics drivers

- [ATI FAQ](https://wiki.gentoo.org/wiki/ATI_FAQ) — Frequently Asked Questions (FAQ) to help users avoid some common installation and configuration issues related to DRI and X11 for AMD/ATI boards.
- [Radeon](https://wiki.gentoo.org/wiki/Radeon) — a family of *open source* graphics drivers for *older* AMD/ATI Radeon graphics cards.
- [AMDGPU](https://wiki.gentoo.org/wiki/AMDGPU) — the open source graphics drivers for AMD Radeon and other GPUs.
- [AMDGPU-PRO](https://wiki.gentoo.org/wiki/AMDGPU-PRO) — the next generation *closed source* graphics component that operates on top of the open source [AMDGPU](https://wiki.gentoo.org/wiki/AMDGPU) drivers for newer AMD/ATI Radeon graphics cards.

### CPUs

- [Ryzen](https://wiki.gentoo.org/wiki/Ryzen) — a multithreaded, high performance processor manufactured by AMD.
- [AMD microcode](https://wiki.gentoo.org/wiki/AMD_microcode) — describes updating the [microcode](https://wiki.gentoo.org/wiki/Microcode) for [AMD] processors.
