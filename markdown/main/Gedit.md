# Gedit

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Gedit** is the [text editor](https://wiki.gentoo.org/wiki/Text_editor) of the [GNOME](https://wiki.gentoo.org/wiki/GNOME) desktop environment. It is written in C and Python.
