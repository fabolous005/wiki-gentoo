# C-Sharp

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**C#** (**C-Sharp**) is an open-source, general-purpose, multi-paradigm, programming language. It was created by Microsoft around the year 2000 and is part of the [.NET framework](https://en.wikipedia.org/wiki/.NET) ("dot net").

C# is compiled to [Common Intermediate Language](https://en.wikipedia.org/wiki/Common_Intermediate_Language) which runs on the [Common Language Runtime](https://en.wikipedia.org/wiki/Common_Language_Runtime) virtual machine which uses [just-in-time compilation](https://en.wikipedia.org/wiki/Just-in-time_compilation).
