### Project Room

We plan to apply for a shared project room of [Gentoo e.V.](https://gentoo-ev.org/) and the [TroLUG](https://trolug.de/). In the project room we can help to install Gentoo, discuss/repair ebuilds and provide buttons and shirts.

Contact vorstand at gentoo-ev.org if you want to join the project room or give a talk or hold a workshop.
