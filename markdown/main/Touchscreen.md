# Touchscreen

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Enabling touchscreen support (generally for laptops and tablets) is commonly possible using the wacom kernel driver and either the wacom (X) or libinput (Wayland) userspace driver.

## Installation

### Kernel

See the [kernel section of the wacom article](https://wiki.gentoo.org/wiki/Wacom#Kernel).

### Userspace driver

See the [libinput article](https://wiki.gentoo.org/wiki/Libinput).
