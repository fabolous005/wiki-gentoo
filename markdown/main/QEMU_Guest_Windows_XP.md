# QEMU/Guest/Windows XP

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)


Libvirt Windows XP guest details the creation and handling of Windows XP guest virtual machine on QEMU host.

## Overview

Windows XP guests use legacy virtual hardware under libvirt with QEMU/KVM. BIOS firmware (SeaBIOS) is required. IDE storage and legacy network devices are required for installation.

Windows XP guests are shaped by libvirt domain definitions generated through [virt-manager](https://wiki.gentoo.org/wiki/Virt-manager), [virsh create](https://wiki.gentoo.org/wiki/Virsh#Create_domain) domain, or [virt-install](https://wiki.gentoo.org/wiki/Virt-install).

This page demonstrates a typical workflow using virt-install to generate the domain XML, followed by virsh for lifecycle control.

## Requirements

Verify that the required components are installed and ready:

- QEMU with KVM support ([QEMU install](https://wiki.gentoo.org/wiki/QEMU#Installation))
- virsh, libvirt daemon ([libvirt install](https://wiki.gentoo.org/wiki/Libvirt#Installation))
- virt-install ([virt-install](https://wiki.gentoo.org/wiki/Virt-install#Installation))
- Windows XP installation ISO
- Optional VirtIO driver ISO ((v0.1.130 to v0.1.137; post-installation only)

## Installation process

This installation process uses qemu-img and virt-install to generate and define a libvirt [domain](https://wiki.gentoo.org/wiki/Libvirt/domain).

Stages:

- Disk image creation
- virt-install domain generation
- Guest installation from CD-ROM
- Post-installation VirtIO migration



### Parameters

Define the parameters for Windows XP guest to be 20GB hard drive, 512MB memory, 'default' networking, and 1 CPU.

`user $``bash`
DOMAIN\_NAME="windows-xp"
RAM\_SIZE\_MB=1024
OS\_ISO\_PATH="/iso/winxp.iso"
VIRTIO\_ISO\_PATH="./Downloads/libvirt-guest-tool.iso"  # v1.137 or older
DISK\_IMAGE\_SIZE=512MB
DISK\_IMAGE\_PATH="/var/lib/libvirt/images/winxp.qcow2"
VCPU\_COUNT=1
NETWORK\_PROFILE="default"

### Virtual disk creation

Create the virtual image file for Windows XP disk.

`root #``qemu-img create -f qcow2 $DISK_IMAGE_PATH $DISK_IMAGE_SIZE`
Add file ownership and permission:

`root #``chown qemu:qemu $DISK_IMAGE_PATH``root #``chmod 600 $DISK_IMAGE_PATH`
### Domain creation

virt-install generates and defines the libvirt domain.

Example Windows XP installation command:

`host$````
virt-install \
```
--os-variant winxp \
 --name  $DOMAIN_NAME \
 --machine pc \
 --cpu host \
 --vcpus  $VCPU_COUNT \
 --video vga \
 --boot cdrom,hd \
 --noautoconsole \
 --memory  $RAM_SIZE_MB \
 --cdrom  $OS_ISO_PATH \
 --disk  $VIRTIO_ISO_PATH,device=cdrom \
 --disk  path=$DISK_IMAGE_PATH,bus=ide \
 --graphics vnc \
 --network network=$NETWORK_PROFILE,model=rtl8139

virt-install performs:

- XML generation
- libvirt domain definition (equivalent to virsh define)
- optional domain start (if enabled)

### Verification

#### XML validation

Before running the domain, verify the domain's XML file generated by libvirt.

Dump generated XML:

`host$``virsh dumpxml windows-xp > windows-xp.xml`
Validate XML structure:

`host$``virt-xml-validate windows-xp.xml`
Validate host virtualization:

`host$``virt-host-validate qemu`
Test QEMU translation:

`host$``virsh domxml-to-native qemu-argv windows-xp.xml`
## VirtIO transition

VirtIO devices are enabled after installation and driver installation.

VirtIO specification can be found here[\[1\]](https://wiki.gentoo.org#cite_note-1)



### Storage migration

Install VirtIO drivers from attached VirtIO ISO before switching devices to VirtIO.

\<disk type='file' device='disk'>
  \<driver name='qemu' type='qcow2'/>
  \<source file='/var/lib/libvirt/images/winxp.qcow2'/>
  \<target dev='vda' bus='virtio'/>
\</disk>



### Graphics configuration

Supported display types:

- VNC
- VGA emulation

SPICE is optional but limited in Windows XP environments.

VirtIO GPU is not supported.



### Network migration

\<interface type='network'>
  \<source network='default'/>
  \<model type='virtio'/>
\</interface>

## Domain management

List domains:

`host$``virsh list --all`
Start domain:

`host$``virsh start $DOMAIN_NAME`
View VM desktop:

`host$``virsh vncdisplay "${DOMAIN_NAME}"`
Shutdown domain:

`host$``virsh shutdown windows-xp`
Force stop:

`host$``virsh destroy windows-xp`
## Removal

Remove domain definition:

`host$``virsh undefine windows-xp`
Remove disk image:

`host$``rm /var/lib/libvirt/images/winxp.qcow2`
## Troubleshooting

### Network failure (no NIC)

Windows XP domain has no connectivity and cannot access network resources.

List the available network profiles:

`host$``virsh net-list --all`
If 'default' is not listed, repair it using:

`host$``virsh net-start default``host$``virsh net-autostart default`


### KVM acceleration not available

Quick check if the KVM module is installed:

`root #``lsmod | grep kvm`
If 'kvm' does not appear, then KVM module is not loaded or is missing.

Load required modules:

`root #``modprobe kvm``root #``modprobe kvm_intel`
\- If on x86, x64, i686, i386 (Intel)

`root #``modprobe kvm_amd`
\- If on AMD64 platform
