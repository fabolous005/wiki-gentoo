# pax

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)


**pax** is a file [archiving utility](https://wiki.gentoo.org/wiki/Data_compression) specified by [POSIX](https://wiki.gentoo.org/wiki/POSIX), intended to replace the [cpio](https://wiki.gentoo.org/wiki/Cpio) utility<sup>[\[1\]](https://wiki.gentoo.org#cite_note-1)</sup>. It was first specified in POSIX-1.2001/2004.

## Installation

### Emerge

`root #``emerge --ask app-arch/pax`
## Removal

### Unmerge

`root #``emerge --ask --depclean --verbose app-arch/pax`
