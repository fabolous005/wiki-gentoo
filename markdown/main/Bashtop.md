# bashtop

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)


**bashtop** is a resource monitor that shows usage and stats for processor, memory, disks, network and processes. It is the first of currently three monitoring programs, being succeeded by [bpytop](https://wiki.gentoo.org/wiki/Bpytop) and [btop](https://wiki.gentoo.org/wiki/Btop).

## Installation

### Emerge

`root #``emerge --ask sys-process/bashtop`
## Usage

To start bashtop, you can run

`user $``bashtop`
