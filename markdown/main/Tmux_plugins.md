# Tmux/plugins

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

[tmux](https://wiki.gentoo.org/wiki/Tmux) plugins enhance user experience by adding or extending functionality.

Plugins documented here:

- [tpm](https://wiki.gentoo.org/wiki/Tmux/plugins/tpm) — manages tmux plugins in an automated manner.
- [tmux-mem-cpu-load](https://wiki.gentoo.org/wiki/Tmux/plugins/tmux-mem-cpu-load) — a small program designed for system monitoring in the status line of [tmux](https://wiki.gentoo.org/wiki/Tmux).
- [resurrect](https://wiki.gentoo.org/wiki/Tmux/plugins/resurrect) - Persists [tmux](https://wiki.gentoo.org/wiki/Tmux) environments across system restarts.

## See also

- [GNU Screen](https://wiki.gentoo.org/wiki/GNU_Screen) — a program that enables the creation of multiple sessions and virtual terminals within a single terminal.
