# Why build from sources

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This page is intended to offer good answers why it is beneficial to build software from sources rather than installing binaries.

Building software from sources ..

- allows use of non-default build options ([USE flags](https://wiki.gentoo.org/wiki/Handbook:Parts/Working/USE))
- allows use of custom compiler/linker flags (e.g. [runtime optimization](https://wiki.gentoo.org/wiki/GCC_optimization), [hardening](https://wiki.gentoo.org/wiki/Hardened_Gentoo), address sanitizer)
- reduces risk of running malicious code unnoticed (since it is harder to conceal in source code than in binaries)
