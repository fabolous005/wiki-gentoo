## Important events

For more information, consult the [\[1\]](https://developers.google.com/open-source/gsoc/timeline).

Upcoming Dates:

February 21 - 18:00 UTC - Gentoo Finds out if the organization has been accepted to this years Google Summer of Code (GSoC)

February 22 - March 18 - Potential GSoC contributors discuss application ideas with mentoring organizations on IRC.

March 18 - 18:00 UTC - GSoC contributor application period begins

April 2 - 18:00 UTC - GSoC contributor application deadline (Don't miss it)
