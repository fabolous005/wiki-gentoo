# Lisp

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Lisp** is a family of programming languages related to the LISP (LISt Processor) language designed by John McCarthy at MIT, first described in a 1960 article in the *Communications of the ACM*. Informally, it refers to [Common Lisp](https://en.wikipedia.org/wiki/Common_Lisp); however, the Lisp family also includes languages such as [Scheme](<https://en.wikipedia.org/wiki/Scheme_(programming_language)>), described in the R*n*RS series of specifications, together with [Emacs Lisp](https://wiki.gentoo.org/wiki/GNU_Emacs) and [Dylan](<https://en.wikipedia.org/wiki/Dylan_(programming_language)>).

## Lisp on Gentoo

### Common Lisp

A number of Common Lisp resources can be found on the [Project:Common Lisp](https://wiki.gentoo.org/wiki/Project:Common_Lisp) page.

Common Lisp implementations available on Gentoo include:

- [dev-lisp/abcl](https://packages.gentoo.org/packages/dev-lisp/abcl) - [Armed Bear Common Lisp](http://abcl.org), a Common Lisp implementation for the JVM
- [dev-lisp/clisp](https://packages.gentoo.org/packages/dev-lisp/clisp) - [GNU CLISP](http://clisp.sourceforge.io/)
- [dev-lisp/clozurecl](https://packages.gentoo.org/packages/dev-lisp/clozurecl) - [ClozureCL](http://ccl.clozure.com), derived from Digitool's MCL product
- [dev-lisp/cmucl](https://packages.gentoo.org/packages/dev-lisp/cmucl) - [CMU Common Lisp](http://www.cons.org/cmucl/)
- [dev-lisp/ecl](https://packages.gentoo.org/packages/dev-lisp/ecl) - [ECL](http://common-lisp.net/project/ecl/), an embeddable Common Lisp implementation
- [dev-lisp/gcl](https://packages.gentoo.org/packages/dev-lisp/gcl) - [GNU Common Lisp](http://www.gnu.org/software/gcl/gcl.html)
- [dev-lisp/sbcl](https://packages.gentoo.org/packages/dev-lisp/sbcl) - [Steel Bank Common Lisp](http://www.sbcl.org/)

### Scheme

A number of Scheme resources can be found on the [Project:Scheme](https://wiki.gentoo.org/wiki/Project:Scheme) page.

Scheme implementations available on Gentoo include:

- [dev-scheme/bigloo](https://packages.gentoo.org/packages/dev-scheme/bigloo) - [Bigloo](http://www-sop.inria.fr/indes/fp/Bigloo/index.html), a practical Scheme compiler with many extensions
- [dev-scheme/chez](https://packages.gentoo.org/packages/dev-scheme/chez) - [Chez](http://cisco.github.io/ChezScheme/), a programming language based on R6RS
- [dev-scheme/gambit](https://packages.gentoo.org/packages/dev-scheme/gambit) - [Gambit](http://www.iro.umontreal.ca/~gambit/), a native Scheme to C compiler and interpreter
- [dev-scheme/gauche](https://packages.gentoo.org/packages/dev-scheme/gauche) - [Gauche](http://practical-scheme.net/gauche/), a Unix system friendly Scheme interpreter
- [dev-scheme/guile](https://packages.gentoo.org/packages/dev-scheme/guile) - [GNU Ubiquitous Intelligent Language for Extensions](http://www.gnu.org/software/guile/)
- [dev-scheme/kawa](https://packages.gentoo.org/packages/dev-scheme/kawa) - [Kawa](http://www.gnu.org/software/kawa/), a Java-based Scheme system and Language Framework
- [dev-scheme/racket](https://packages.gentoo.org/packages/dev-scheme/racket) - [Racket](https://wiki.gentoo.org/wiki/Racket), a general purpose, multi-paradigm Lisp-Scheme programming language
