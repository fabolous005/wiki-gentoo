# Winetricks

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Winetricks** is an easy way to work around problems in [Wine](https://wiki.gentoo.org/wiki/Wine).

It is a [Shell](https://wiki.gentoo.org/wiki/Shell) script allowing for easy installation of applications, DLLs, fonts, workarounds, and more.


`root #``emerge --ask app-emulation/winetricks`
