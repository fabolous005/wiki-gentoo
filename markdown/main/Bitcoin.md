Bitcoin is a cryptocurrency created in 2009 by [Satoshi Nakamoto](https://en.wikipedia.org/wiki/Satoshi_Nakamoto).

## Available software

Clients:

- [net-p2p/bitcoin-qt](https://packages.gentoo.org/packages/net-p2p/bitcoin-qt): Bitcoin client using the Qt toolkit.
- [net-misc/electrum](https://packages.gentoo.org/packages/net-misc/electrum): An easy Bitcoin client using the Qt toolkit.
