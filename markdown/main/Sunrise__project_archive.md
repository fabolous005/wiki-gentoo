# Sunrise (project archive)

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article is **archived (obsolete)**. Contents are surely incorrect for current usage, and are intended for historical reference only.

TLDR:

**Do not use this article!**


**Project Sunrise** (also known as the **Sunrise overlay**) used to provide a community-maintained overlay of good-quality packages not in the Gentoo ebuild repository. This page serves as a memorial to the project.

## Alternatives to Sunrise

Sunrise was mostly superseded by the [Proxy Maintainers](https://wiki.gentoo.org/wiki/Project:Proxy_Maintainers) and [GURU](https://wiki.gentoo.org/wiki/Project:GURU) projects which allow community members to maintain packages directly in either the Gentoo ebuild repository or the GURU overlay.

It is also possible to maintain the packages in a private repository. There were a few repositories with the purpose of collecting various 'beta-quality' packages with more or less open access over time. However, none of them reached the status of an official project or really wide audience.

Some of the Gentoo projects also have their own repositories in which they work along with users. For example, this is the workflow used by [the Science project](https://wiki.gentoo.org/wiki/Project:Science) (in [sci](https://gitweb.gentoo.org/proj/sci.git/) repository).
