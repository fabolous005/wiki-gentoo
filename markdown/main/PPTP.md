# PPTP

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The Point-to-Point Tunneling Protocol (**PPTP**) is a method for creating virtual private networks. PPTP allows the [Point-to-Point Protocol](https://en.wikipedia.org/wiki/Point-to-Point_Protocol) (PPP) to be tunneled through an IP network on TCP port 1723.
