This page provides a list of end-user software for working with fonts.

## Software available via the main ('`gentoo`') repository

| Program | Package | Description | 
|---|---|---|
| [bdftopcf(1)](https://man.archlinux.org/man/bdftopcf.1.en) | [x11-apps/bdftopcf](https://packages.gentoo.org/packages/x11-apps/bdftopcf) | Convert X font from Bitmap Distribution Format to Portable Compiled Format | 
| [cfftot1(1)](https://man.archlinux.org/man/cfftot1.1.en) | [app-text/lcdf-typetools](https://packages.gentoo.org/packages/app-text/lcdf-typetools) | Convert PostScript font from CFF to Type 1 | 
| [fc-cache(1)](https://man.archlinux.org/man/fc-cache.1.en) | [media-libs/fontconfig](https://packages.gentoo.org/packages/media-libs/fontconfig) | Build font information cache files | 
| [fc-conflist(1)](https://man.archlinux.org/man/fc-conflist.1.en) | [media-libs/fontconfig](https://packages.gentoo.org/packages/media-libs/fontconfig) | List the configuration files processed by fontconfig | 
| [fc-list(1)](https://man.archlinux.org/man/fc-list.1.en) | [media-libs/fontconfig](https://packages.gentoo.org/packages/media-libs/fontconfig) | List available fonts | 
| [fc-match(1)](https://man.archlinux.org/man/fc-match.1.en) | [media-libs/fontconfig](https://packages.gentoo.org/packages/media-libs/fontconfig) | Match available fonts: list font(s) that best match(es) certain criteria | 
| [fc-query(1)](https://man.archlinux.org/man/fc-query.1.en) | [media-libs/fontconfig](https://packages.gentoo.org/packages/media-libs/fontconfig) | Query font files | 
| [ftbench(1)](https://man.archlinux.org/man/ftbench.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Benchmark some common FreeType paths | 
| [ftdiff(1)](https://man.archlinux.org/man/ftdiff.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Compare font hinting modes | 
| [ftdump(1)](https://man.archlinux.org/man/ftdump.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Simple font dumper | 
| [ftgamma(1)](https://man.archlinux.org/man/ftgamma.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Screen gamma calibration helper | 
| [ftgrid(1)](https://man.archlinux.org/man/ftgrid.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Simple glyph grid viewer | 
| [ftlint(1)](https://man.archlinux.org/man/ftlint.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Simple font tester | 
| [ftmulti(1)](https://man.archlinux.org/man/ftmulti.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Multiple masters font viewer | 
| [ftsdf(1)](https://man.archlinux.org/man/ftsdf.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | A Signed Distance Fields viewer | 
| [ftstring(1)](https://man.archlinux.org/man/ftstring.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | String viewer | 
| [ftvalid(1)](https://man.archlinux.org/man/ftvalid.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Font layout table validator | 
| [ftview(1)](https://man.archlinux.org/man/ftview.1.en) | [media-libs/freetype](https://packages.gentoo.org/packages/media-libs/freetype) (with `utils` USE flag) | Simple glyph viewer | 
| [otfinfo(1)](https://man.archlinux.org/man/otfinfo.1.en) | [app-text/lcdf-typetools](https://packages.gentoo.org/packages/app-text/lcdf-typetools) | Report information about OpenType fonts | 
| [pango-list(1)](https://man.archlinux.org/man/pango-list.1.en) | [x11-libs/pango](https://packages.gentoo.org/packages/x11-libs/pango) | List fonts available to the Pango layout and rendering library | 
| [pango-view(1)](https://man.archlinux.org/man/pango-view.1.en) | [x11-libs/pango](https://packages.gentoo.org/packages/x11-libs/pango) | Format text using the Pango layout and rendering library | 
| [pdffonts(1)](https://man.archlinux.org/man/pdffonts.1.en) | [app-text/poppler](https://packages.gentoo.org/packages/app-text/poppler) (with `utils` USE flag) | Lists the fonts used in a PDF along with various information for each font | 
| [psfaddtable(1)](https://man.archlinux.org/man/psfaddtable.1.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Add a Unicode character table to a console font | 
| [psfgettable(1)](https://man.archlinux.org/man/psfgettable.1.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Extract the embedded Unicode character table from a console font | 
| [psfstriptable(1)](https://man.archlinux.org/man/psfstriptable.1.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Remove the embedded Unicode character table from a console font | 
| [psfxtable(1)](https://man.archlinux.org/man/psfxtable.1.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Handle Unicode character tables for console fonts | 
| [setfont(8)](https://man.archlinux.org/man/setfont.8.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Set console font | 
| [showconsolefont(8)](https://man.archlinux.org/man/showconsolefont.8.en) | [sys-apps/kbd](https://packages.gentoo.org/packages/sys-apps/kbd) | Show glyphs of current console font | 
| [tfmtodit(1)](https://man.archlinux.org/man/tfmtodit.1.en) | [sys-apps/groff](https://packages.gentoo.org/packages/sys-apps/groff) | Adapt TeX Font Metrics files for use with groff and grodvi | 
| [ttf2afm(1)](https://man.archlinux.org/man/ttf2afm.1.en) | [app-text/texlive-core](https://packages.gentoo.org/packages/app-text/texlive-core) | Generate AFM files for TrueType fonts | 
| [ttfdump(1)](https://man.archlinux.org/man/ttfdump.1.en) | [app-text/texlive-core](https://packages.gentoo.org/packages/app-text/texlive-core) | Dump the contents of a TrueType Font file |
