**Bugday focus: Python 3.9**

## Topic 1: Move to Python 3.9

Search packages, which are not yet based on Python 3.9 and update them.

### Resources

- Tracker for Python3.9 porting [bug #725490](https://bugs.gentoo.org/show_bug.cgi?id=725490)
- QA tracker: [https://qa-reports.gentoo.org/output/gpyutils/38-to-39.txt](https://qa-reports.gentoo.org/output/gpyutils/38-to-39.txt)

## Topic 2: Verify old bugs and check if they are still reproducible

Search old bug tickets and check if it is solved already / still reproducible with latest version
