# Matrix

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Matrix** is a real-time communication protocol. It is federated and open standard, that let's users interact while using different service providers.

The protocol includes:

- Direct and group (aka. rooms) messages
- Encryption with Olm
- Voice and video calls
- Typing notifications
- Message receipts
- Message reactions
- Avatars
- User statuses
- Media uploads
- Room directories

...and more

## Clients

Most popular clients can be found on the [Matrix Ecosystem Clients](https://matrix.org/ecosystem/clients/) page.
