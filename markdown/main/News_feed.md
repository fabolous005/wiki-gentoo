# News feed

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**News feed** (or **web feed**) is a computer-readable data format for content updates. The most common feeds are RSS and Atom (RFC 4287).

## Available software

### Feed readers

Feed readers reside within the [net-news](https://packages.gentoo.org/categories/net-news) category. To list them, run:

`user $``eix -cC net-news`
### Web browser support

[Pale Moon](https://wiki.gentoo.org/index.php?title=Pale_Moon&action=edit&redlink=1) has native support for feed autodiscovery and listing. Other browsers need a third-party extension for that functionality.

### Web applications

Selfhosted news aggregation applications give such benefits as easy synchronization between devices or [email](https://wiki.gentoo.org/wiki/Email) notifications.

- [www-apps/nextcloud](https://packages.gentoo.org/packages/www-apps/nextcloud) with the [News](https://apps.nextcloud.com/apps/news) application installed
- [www-apps/selfoss](https://packages.gentoo.org/packages/www-apps/selfoss)
- [www-apps/tt-rss](https://packages.gentoo.org/packages/www-apps/tt-rss)
