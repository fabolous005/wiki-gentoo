# ChromeOS

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

*Not to be confused with[wikipedia:Chromium OS](https://en.wikipedia.org/wiki/Chromium_OS).*

**ChromeOS** is an operating system developed almost exclusively by Google in order to be used on the Chromebook hardware line.

ChromeOS is built<sup>[\[1\]](https://wiki.gentoo.org#cite_note-1)</sup> using [Portage](https://wiki.gentoo.org/wiki/Portage)<sup>[\[2\]](https://wiki.gentoo.org#cite_note-2)</sup>, Gentoo's package manager, and Gentoo-based [chroots](https://wiki.gentoo.org/wiki/Chroot)<sup>[\[3\]](https://wiki.gentoo.org#cite_note-3)</sup>. ChromeOS uses the [upstart](<https://en.wikipedia.org/wiki/Upstart_(software)>) [init system](https://wiki.gentoo.org/wiki/Init_system).

[ChromeOS Flex](https://chromeenterprise.google/os/chromeosflex/) now allows ChromeOS to be installed on many commodity machines.
