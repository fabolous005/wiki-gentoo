# Manim

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Manim** is a community maintained Python library for creating mathematical animations. The most popular youtuber and creator of Manim is [3blue1brown](https://www.youtube.com/@3blue1brown).

## Installation

Manim can be installed via [pip](https://wiki.gentoo.org/wiki/Pip#Package_installation).

### LaTex

To use LaTex, install [app-text/texlive](https://packages.gentoo.org/packages/app-text/texlive) with `extra` and `science` USE flag.

## Usage

There is a [quickstart](https://docs.manim.community/en/stable/tutorials/quickstart.html) tutorial to get beginners started.
To play videos/images, browse through the media directory and play with a video player or web browser.
