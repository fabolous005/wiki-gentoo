# Hex editor

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

A **hex editor** is an application to allow viewing and editing of [binary files](https://en.wikipedia.org/wiki/Binary_file), as opposed to [text files](https://wiki.gentoo.org/wiki/Text_editor).

## Available software

This is just a partial selection of hex editors available in Gentoo, see [app-editors](https://packages.gentoo.org/categories/app-editors) for more options.

| Name | Package | Description | 
|---|---|---|
| curses-hexedit | [app-editors/curses-hexedit](https://packages.gentoo.org/packages/app-editors/curses-hexedit) | Full screen curses hex editor (with insert/delete support). | 
| dhex | [app-editors/dhex](https://packages.gentoo.org/packages/app-editors/dhex) | Ncurses-based hex-editor with diff mode. | 
| ghex | [app-editors/ghex](https://packages.gentoo.org/packages/app-editors/ghex) | A GTK-based hexadecimal editor. | 
| hexcurse | [app-editors/hexcurse](https://packages.gentoo.org/packages/app-editors/hexcurse) | Ncurses based hex editor. | 
| hexedit | [app-editors/hexedit](https://packages.gentoo.org/packages/app-editors/hexedit) | View and edit files in hex or ASCII. | 
| hyx | [app-editors/hyx](https://packages.gentoo.org/packages/app-editors/hyx) | Minimalistic console hex editor with vim-like controls. | 
| imhex | [app-editors/imhex](https://packages.gentoo.org/packages/app-editors/imhex) | Fancy hex editor with custom pattern language, diffing, editing, ... in [GURU](https://wiki.gentoo.org/wiki/GURU) repo | 
| okteta | [app-editors/okteta](https://packages.gentoo.org/packages/app-editors/okteta) | Hex editor by KDE. | 
| qhexedit2 | [app-editors/qhexedit2](https://packages.gentoo.org/packages/app-editors/qhexedit2) | Hex editor library, Qt application written in C++ with Python bindings. | 
| shed | [app-editors/shed](https://packages.gentoo.org/packages/app-editors/shed) | Simple Hex EDitor. | 
| wxhexeditor | [app-editors/wxhexeditor](https://packages.gentoo.org/packages/app-editors/wxhexeditor) | A cross-platform hex editor designed specially for large files. | 
| xxd | [app-editors/vim](https://packages.gentoo.org/packages/app-editors/vim) | A console-based text editor supplied with [Vim](https://wiki.gentoo.org/wiki/Vim). Also available as a separate package, *dev-util/xxd*, from the [GURU](https://wiki.gentoo.org/wiki/GURU) ebuild repository. In (Neo-)vim check: `:help hex-editing`. |
