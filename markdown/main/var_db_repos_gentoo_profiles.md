# /var/db/repos/gentoo/profiles

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/var/db/repos/gentoo/profiles** is a directory that contains global [profiles](<https://wiki.gentoo.org/wiki/Profile_(Portage)>) that are controlled by developers of the Gentoo ebuild repository (gentoo.git). One of them needs to be [selected as the system profile](https://wiki.gentoo.org/wiki/Handbook:AMD64/Installation/Base#Choosing_the_right_profile). To override these settings, use the files in the [/etc/portage/profile/](https://wiki.gentoo.org/wiki//etc/portage) directory.

- [/var/db/repos/gentoo/profiles/package.mask](https://wiki.gentoo.org/wiki//var/db/repos/gentoo/profiles/package.mask) — a file containing package atoms to mask.
