# OpenRC/Users

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This is an (incomplete) list of distributions and operating systems using OpenRC.

## Default

On these systems, OpenRC is the default init system.

- [Alpine Linux](https://alpinelinux.org/)
- [ArchBang](http://www.archbang.org/) - Arch based.
- [Calculate Linux](https://www.calculate-linux.org/) - Gentoo based.
- [Daphile](https://www.daphile.com) - Gentoo based music server and player distribution.
- [Funtoo Linux](http://www.funtoo.org/)
- [Gentoo Linux](https://www.gentoo.org/)
- [GhostBSD](http://www.ghostbsd.org/) - FreeBSD based.
- [Nitrux](https://nxos.org/) - Debian based.
- [Redcore Linux](https://redcorelinux.org/) - Gentoo based.
- [TrueOS](https://www.trueos.org/) - FreeBSD based (discontinued).
