# Cgroups

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**cgroups** ("control groups") on Linux allow securely managing the system resource usage of processes.

## See also

- [Namespaces](https://wiki.gentoo.org/wiki/Namespaces) — wrap system resources, making processes within that namespace appear to have isolated instances of that resource
- [OpenRC/CGroups](https://wiki.gentoo.org/wiki/OpenRC/CGroups) — OpenRC includes support for [cgroups].
