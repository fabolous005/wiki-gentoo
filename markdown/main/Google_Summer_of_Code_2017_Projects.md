## Projects

The following projects have been accepted to GSoC 2017
<sup>[\[1\]](https://wiki.gentoo.org#cite_note-1)</sup>:

### A utility to manage packages in overlays (pomu)

| Participant(s): | Mykyta Holubakha | 
| Mentor(s): | [Brian Dolbec (dolsen)](https://wiki.gentoo.org/wiki/User:Dol-sen) | 
| Repository | [mykytaholubakha/pomu.git](https://gitweb.gentoo.org/mirror/gsoc/2017/mykytaholubakha/pomu.git/) | 
| Website/Wiki-Page: | [pomu](https://wiki.gentoo.org/wiki/User:Hummer12007/pomu) | 

"The goal of the project is to enable the user to efficiently manage a
local overlay (by adding new packages from external sources or
packages from the portage tree to make some edits, etc.)."

### Support for Varied MPI Implementations

| Participant(s): | Michael Gilroy | 
| Mentor(s): | [Andrew Savchenko (bircoph)](https://wiki.gentoo.org/wiki/User:Bircoph) [Justin Bronder (jsbronder)](https://wiki.gentoo.org/wiki/User:Jsbronder) | 
| Repository | [michaelgilroy/gentoo-mpi.git](https://gitweb.gentoo.org/mirror/gsoc/2017/michaelgilroy/gentoo-mpi.git/) | 
| Website/Wiki-Page: | [Gentoo-mpi-overlay](https://wiki.gentoo.org/wiki/Gentoo-mpi-overlay) | 

"There are numerous MPI (Message Passing Interface) implementations available, but most of them can't be installed together as is. In HPC world it is often mandatory to provide for users different MPI implementations and/or versions of the same implementation, e.g. due to binary package dependencies, codebase or performance issues."
[\[5\]](https://wiki.gentoo.org#cite_note-5)
