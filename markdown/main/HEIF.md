# HEIF

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article provides configuration information to add HEIF container format support to [desktop environments](https://wiki.gentoo.org/wiki/Desktop_environment) supporting its integration.

HEIF formatted files can be generated by Apple or Android phones and typically end with a **.heic** file extension suffix.

## USE flags

### Global

Several packages are aware of the global [heif](https://packages.gentoo.org/useflags/heif) [USE flag. Enable it in /etc/portage/make.conf like:](https://wiki.gentoo.org/wiki/USE_flag)

**`/etc/portage/make.conf`**

```
USE="... heif ..."
```
Then perform a world upgrade:

`root #``emerge --ask --changed-use --deep --update @world`
## Desktop environments

### GNOME 3

In order for software in the GNOME suite of desktop applications to display HEIF encoded files (typically ending with the .heic file extension suffix), the `gdk-pixbuf` USE flag must be enabled for the [media-libs/libheif](https://packages.gentoo.org/packages/media-libs/libheif) package.

It is likely that users of GNOME will want to enable [gdk-pixbuf](https://packages.gentoo.org/useflags/gdk-pixbuf) [globally in /etc/portage/make.conf for general better integration.](https://wiki.gentoo.org/wiki/USE_flag)

This example will only enable support for the libheif library itself:

**`/etc/portage/package.use/libheif`**

**Enable libheif's gdk-pixbuf plugin to be built**

Rebuild the world set so that the changes take effect:

`root #``emerge -uND --with-bdeps=y @world`
Update the loaders.cache file in order to discover the newly added plugin:

`root #``gdk-pixbuf-query-loaders --update-cache`
Image files of the HEIF type should now properly open and render in GNOME's Image Viewer ([media-gfx/eog](https://packages.gentoo.org/packages/media-gfx/eog)).

### KDE

In order for software in the KDE suite of desktop applications to display HEIF encoded files, the `heif` USE flag must be enabled for the [kde-frameworks/kimageformats](https://packages.gentoo.org/packages/kde-frameworks/kimageformats) package.

Update the use flags:

**`/etc/portage/package.use/kimageformats`**

Emerge kimageformats:

`root #``emerge --ask kde-frameworks/kimageformats`
This will allow for viewing files with the **.heic** extension in Gwenview and enable thumbnail support in Dolphin.
