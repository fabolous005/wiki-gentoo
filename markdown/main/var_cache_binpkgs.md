# /var/cache/binpkgs

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/var/cache/binpkgs** is the directory Portage uses to store prebuilt (binary) packages.  This directory is defined in /usr/share/portage/config/make.globals and can be altered by changing the value of the `[PKGDIR](https://wiki.gentoo.org/wiki/PKGDIR)` variable in [make.conf](https://wiki.gentoo.org/wiki//etc/portage/make.conf).
