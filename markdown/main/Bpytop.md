# bpytop

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)


**bpytop** is a resource monitor that shows usage and stats for processor, memory, disks, network and processes. It is a continuation of [bashtop](https://wiki.gentoo.org/wiki/Bashtop) and succeeded by [btop](https://wiki.gentoo.org/wiki/Btop).

## Installation

### Emerge

`root #``emerge --ask sys-process/bpytop`
## Usage

To start bpytop, you can run

`user $``bpytop`
