# Google Summer of Code/2023/Ideas/Project Pen Too: Profile 42 - Don't panic! Gentoo for everyone

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The aim of this project is to provide a secure, easy-to-use, reliable Gentoo based desktop operating system for everyone on modern hardware. I.e. an image which can be written directly to a data medium, where all applications for daily work are pre-installed and which can be used every day. A operating system which belongs to you. That you can use and modify as needed and according to your own wishes. One that you own.

Having a secure operating system is one of the pillars for having secure communications.

There are a lot of people who have paranoia. If it is with reason or without does not make a difference. This project might help those people in need to have trust in a secure and reliable operating system that they can use daily.

For further information and a proof of concept see this github repository
[https://github.com/allan-gounden/Project-Pen-Too](https://github.com/allan-gounden/Project-Pen-Too)
