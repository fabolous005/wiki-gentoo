# License groups/OSI-APPROVED

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Open-source licenses approved by the Open Source Initiative [\[1\]](https://opensource.org/licenses).

## OSI-APPROVED-FREE

Open-source licenses that are free. This excludes the licenses from the [OSI-APPROVED-NONFREE](https://wiki.gentoo.org#OSI-APPROVED-NONFREE) set. We keep Artistic because Debian considers it DFSG-free.

## OSI-APPROVED-NONFREE
