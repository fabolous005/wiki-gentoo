# /etc/portage/savedconfig

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/etc/portage/savedconfig** is the directory for persistent package configuration.

Packages having the [savedconfig](https://wiki.gentoo.org/wiki/Savedconfig)[sys-kernel/linux-firmware](https://packages.gentoo.org/packages/sys-kernel/linux-firmware) and [sys-apps/busybox](https://packages.gentoo.org/packages/sys-apps/busybox) put files here.
