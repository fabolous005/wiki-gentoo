# Leafpad

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Leafpad is an extremely simple, yet functional, GTK2 text editor. It is the default text editor used by [LXDE](https://wiki.gentoo.org/wiki/LXDE).[\[1\]](https://wiki.gentoo.org#cite_note-1)

## Features

Some of Leafpad's features<sup>[\[2\]](https://wiki.gentoo.org#cite_note-2)</sup> include:

- Codeset option (Some OpenI18N registered)
- Auto codeset detection (UTF-8 and some codesets)
- Unlimitted Undo/Redo
- Auto/Multi-line Indent
- Display line numbers
- Drag and Drop
- Printing
