# /var/cache/distfiles

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/var/cache/distfiles** is the default directory [Portage](https://wiki.gentoo.org/wiki/Portage) uses to store source code files. These are typically in a compressed package format. [Portage](https://wiki.gentoo.org/wiki/Portage) defines this default value in /usr/share/portage/config/make.globals, and this directory definition can be altered by changing the value of the `[DISTDIR](https://wiki.gentoo.org/wiki/DISTDIR)` variable in [make.conf](https://wiki.gentoo.org/wiki//etc/portage/make.conf).
