# Android/SharkBait

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**Resources**

![](https://wiki.gentoo.org/images/thumb/a/a6/Mako.png/300px-Mako.png)

A project to create a recognizable identity and foster development of [Portage-powered Android](https://wiki.gentoo.org/wiki/Google_Summer_of_Code/2018/Ideas/Portage_powered_Android).

## History

SharkBait was originally an idea submitted by [Heroxbd](https://wiki.gentoo.org/wiki/User:Heroxbd) as part of [Google Summer of Code (GSoC) 2018](https://wiki.gentoo.org/wiki/Google_Summer_of_Code/2018).
