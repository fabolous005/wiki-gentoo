# Desktop environment

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article provides a list of desktop environments available in Gentoo.

A **desktop environment** is a [complete ecosystem of software and resources](https://en.wikipedia.org/wiki/Desktop_environment) providing a homogeneous graphical user experience. Generally based on specific [graphical widgets](https://en.wikipedia.org/wiki/Graphical_widget), configuration system, [root window](https://en.wikipedia.org/wiki/Root_window) with desktop background, [taskbar](https://en.wikipedia.org/wiki/Taskbar) with window list and menu, icons, [window manager](https://wiki.gentoo.org/wiki/Window_manager) etc. It provides a coherent visual metaphor for a user to interact with the computer.

A desktop environment can be a great convenience to many users, though a custom graphical environment can be assembled if preferred, i.e. Xorg could be used with a window manager and select desktop utilities. Gentoo's flexibility means that many desktop environments are available, and more than one can generally be installed in parallel. Gentoo can of course be used exclusively in text mode, as a server platform for example.

Gentoo does not have separate [releases](https://wiki.gentoo.org/wiki/FAQ#Can_I_upgrade_Gentoo_from_one_release_to_another_without_reinstalling.3F) or "flavors" for different desktop environments, as some other distributions do - a desktop environment is simply installed on the base system.

## Available software

| Name | Package | Description | 
|---|---|---|
| [Cinnamon](https://wiki.gentoo.org/wiki/Cinnamon) | [gnome-extra/cinnamon](https://packages.gentoo.org/packages/gnome-extra/cinnamon) | GNOME 3 fork with a traditional Windows-like interface. | 
| [Enlightenment](https://wiki.gentoo.org/wiki/Enlightenment) | [x11-wm/enlightenment](https://packages.gentoo.org/packages/x11-wm/enlightenment) | Eye-candy, compositing and stacking [window manager](https://wiki.gentoo.org/wiki/Window_manager) that is released under the permissive BSD License. | 
| [FVWM-Crystal](https://wiki.gentoo.org/wiki/FVWM-Crystal) | [x11-themes/fvwm-crystal](https://packages.gentoo.org/packages/x11-themes/fvwm-crystal) | Easy to use, powerful and pretty desktop environment. | 
| [GNOME](https://wiki.gentoo.org/wiki/GNOME) | [gnome-base/gnome](https://packages.gentoo.org/packages/gnome-base/gnome) | One of the most widely-used desktop environments for Linux. A lighter alternative, [gnome-base/gnome-light](https://packages.gentoo.org/packages/gnome-base/gnome-light), is also available. Quite a few forks of GNOME have been created, including Cinnamon (early GNOME 3) and MATE (late GNOME 2). | 
| [KDE Plasma](https://wiki.gentoo.org/wiki/Plasma) | [kde-plasma/plasma-meta](https://packages.gentoo.org/packages/kde-plasma/plasma-meta) | Based on Qt6 and KDE Frameworks 6. This is the desktop environment only. A wide range of related applications are available separately with [kde-apps/kde-apps-meta](https://packages.gentoo.org/packages/kde-apps/kde-apps-meta). | 
| [LXDE](https://wiki.gentoo.org/wiki/LXDE) | [lxde-base/lxde-meta](https://packages.gentoo.org/packages/lxde-base/lxde-meta) | Lightweight X11 Desktop Environment. | 
| [LXQt](https://wiki.gentoo.org/wiki/LXQt) | [lxqt-base/lxqt-meta](https://packages.gentoo.org/packages/lxqt-base/lxqt-meta) | Lightweight desktop environment based on the Qt toolkit. | 
| [MATE](https://wiki.gentoo.org/wiki/MATE) | [mate-base/mate](https://packages.gentoo.org/packages/mate-base/mate) | Fork of the GNOME 2 desktop environment. | 
| [Xfce](https://wiki.gentoo.org/wiki/Xfce) | [xfce-base/xfce4-meta](https://packages.gentoo.org/packages/xfce-base/xfce4-meta) | Fully featured lightweight desktop environment. | 

### 3rd party repositories

These packages are available from third party repositories, they are not officially supported by Gentoo.

| Name | Description | 
|---|---|
| [Budgie](https://wiki.gentoo.org/wiki/Budgie) | The Budgie Desktop is a feature-rich, modern desktop designed to keep out the way of the user, focuses on simplicity and elegance. | 
| [COSMIC](https://wiki.gentoo.org/wiki/COSMIC) | A desktop environment built by System76 in Rust. | 
| [Deepin Desktop Environment](https://wiki.gentoo.org/wiki/DDE) | Elegant, easy to use and reliable domestic desktop environment. | 
| [Pantheon](https://wiki.gentoo.org/wiki/Pantheon) | New lightweight, modular desktop environment primarily written in Vala. | 
| [SonicDE](https://github.com/sonicde-gentoo/portage) | A fork of KDE Plasma aimed at continued support of X11. | 
| [Trinity Desktop Environment](https://wiki.gentoo.org/wiki/Trinity_Desktop_Environment) | A free and open-source desktop environment forked from KDE 3.5. | 
| [Unity](https://wiki.gentoo.org/wiki/Unity) | An alternative shell for the GNOME desktop environment, developed by Canonical in its Ayatana project. |
