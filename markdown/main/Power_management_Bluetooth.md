# Power management/Bluetooth

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article describes the setup of [power management](https://wiki.gentoo.org/wiki/Power_management) of Bluetooth devices.

## Configuration

### Udev

Make the following [udev](https://wiki.gentoo.org/wiki/Udev) rule file to automate power management:

FILE **`/etc/udev/rules.d/10-my-bluetooth-power.rules`**
