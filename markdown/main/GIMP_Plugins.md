# GIMP/Plugins

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The following plugins for GIMP are available in the Portage tree:

| Plugin | Description | 
|---|---|
| [media-gfx/gimp-arrow-brushes](https://packages.gentoo.org/packages/media-gfx/gimp-arrow-brushes) | Brushes for GIMP including the styles arrow, handpointer, button arrow and cursor. | 
| [media-plugins/gimp-lqr](https://packages.gentoo.org/packages/media-plugins/gimp-lqr) | Content-aware resizing for the GIMP | 


More plugins can be found online at [http://registry.gimp.org/](http://registry.gimp.org/)
