# /etc/portage/package.unmask

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

**/etc/portage/package.unmask** is a file containing a list of packages that are to be unmasked. It is similar to the [package.mask](https://wiki.gentoo.org/wiki//etc/portage/package.mask) file and useful for overriding values set in Portage's global package.mask file.
