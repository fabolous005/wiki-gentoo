# Hardware detection

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article lists and describes utilities used to detect and provide information on hardware. See the respective article for additional details on each utility.

## Available software

| Utility | Package | Description | 
|---|---|---|
| [dmidecode](https://wiki.gentoo.org/wiki/Dmidecode) | [sys-apps/dmidecode](https://packages.gentoo.org/packages/sys-apps/dmidecode) | DMI (Desktop Management Interface) table related utilities | 
| [hdparm](https://wiki.gentoo.org/wiki/Hdparm) | [sys-apps/hdparm](https://packages.gentoo.org/packages/sys-apps/hdparm) | hdparm is a command line utility to set and view ATA & SATA hard disk drive hardware parameters. | 
| [hwinfo](https://wiki.gentoo.org/wiki/Hwinfo) | [sys-apps/hwinfo](https://packages.gentoo.org/packages/sys-apps/hwinfo) | The hardware detection utility of OpenSUSE. | 
| [hw-probe](https://wiki.gentoo.org/wiki/Hw-probe) | [sys-apps/hw-probe](https://packages.gentoo.org/packages/sys-apps/hw-probe) | Probe for hardware, check its operability and upload result to the Linux hardware DB: [https://linux-hardware.org](https://linux-hardware.org) | 
| inxi | [sys-apps/inxi](https://packages.gentoo.org/packages/sys-apps/inxi) | A system information script for [IRC](https://wiki.gentoo.org/wiki/IRC) and system administrators. | 
| [libinput list-devices](https://wiki.gentoo.org/wiki/Libinput#Invocation) | [dev-libs/libinput](https://packages.gentoo.org/packages/dev-libs/libinput) | list local devices as recognized by libinput | 
| [lpinfo](https://wiki.gentoo.org/wiki/Printing#lpinfo) | [net-print/cups](https://packages.gentoo.org/packages/net-print/cups) | Lists all printers and the available drivers (.ppd files). | 
| lsinput | [sys-apps/input-utils](https://packages.gentoo.org/packages/sys-apps/input-utils) | Small collection of linux input layer utils | 
| [lshw](https://wiki.gentoo.org/wiki/Lshw) | [sys-apps/lshw](https://packages.gentoo.org/packages/sys-apps/lshw) | Generates a structured list of detected hardware and their features. | 
| [lspci](https://wiki.gentoo.org/wiki/Pciutils) | [sys-apps/pciutils](https://packages.gentoo.org/packages/sys-apps/pciutils) | Includes command-line tools for identifying PCI system hardware. | 
| [lsusb](https://wiki.gentoo.org/wiki/Usbutils) | [sys-apps/usbutils](https://packages.gentoo.org/packages/sys-apps/usbutils) | Includes command-line tools for identifying USB system hardware. | 
| [i2cdetect](https://wiki.gentoo.org/wiki/I2C) | [sys-apps/i2c-tools](https://packages.gentoo.org/packages/sys-apps/i2c-tools) | I2C tools for bus probing, chip dumping, register-level access helpers, EEPROM decoding, and more. | 
| [sensors-detect](https://wiki.gentoo.org/wiki/Lm_sensors) | [sys-apps/lm-sensors](https://packages.gentoo.org/packages/sys-apps/lm-sensors) | Detects temperature sensors | 
| [Scan modem](https://wiki.gentoo.org/wiki/Scan_modem) | Not applicable | scanModem.sh is a script used for finding suited driver for connected modems. |
