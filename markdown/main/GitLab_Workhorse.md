# GitLab/Workhorse

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Gitlab-Workhorse provides a reverse proxy, wrapping Gitlab-Shell, that handles the more bulky uploads/downloads performed by Gitlab.

## Installation

This package is installed as a part of Gitlab

## Uninstallation

This package is removed as a part of Gitlab
