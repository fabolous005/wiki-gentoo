# pgo (disambiguation)

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Within the Gentoo project space, the term "**pgo**" can have several different meanings that include:

- [packages.gentoo.org](https://wiki.gentoo.org/wiki/Packages.gentoo.org) - website that provides information about packages available in the [Gentoo ebuild repository](https://wiki.gentoo.org/wiki/Ebuild_repository#The_Gentoo_ebuild_repository) (*p.g.o*).
- [Profile Guided Optimization](https://wiki.gentoo.org/wiki/GCC_optimization#Profile_Guided_Optimization_.28PGO.29) - Profile Guided Optimization (*PGO*).
