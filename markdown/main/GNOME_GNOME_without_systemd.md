# GNOME/GNOME without systemd

From Gentoo Wiki

\< [GNOME](https://wiki.gentoo.org/wiki/GNOME)

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The popular GNOME 3 desktop environment may be used under the OpenRC init system in Gentoo (as well as the default systemd).

Currently, OpenRC interoperability is provided via two distinct approaches:

1. [Official Gentoo support](https://blogs.gentoo.org/leio/2019/03/26/gnome-3-30/) is provided for GNOME-3.30+. Installation instructions may be found **[here](https://wiki.gentoo.org/wiki/GNOME/GNOME_without_systemd/Gentoo)**.
2. Dantrell provides a set of overlays, targeting GNOME-3.14+, as part of his [GNOME without systemd](https://github.com/dantrell/gentoo-project-gnome-without-systemd) project. Installation instructions may be found **[here](https://wiki.gentoo.org/wiki/GNOME/GNOME_without_systemd/Dantrell)**.
