# Acer ao756-2840

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

The **Acer AO756** is a laptop with an Intel Celeron 847 processor, 2GB of RAM, 3 USB 2.0 ports, and VGA, HDMI, and LAN interfaces.

## Troubleshooting

### Backlight does not work

In order to be able to control the backlight, the following kernel parameters should be applied:

```
acpi_backlight=vendor acpi_osi=Linux
```
