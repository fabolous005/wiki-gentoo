# Heartbeat

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

This article is

**archived (obsolete)**. Contents are surely incorrect for current usage, and are intended for historical reference only.

Package no longer in Gentoo repository.

TLDR:

**Do not use this article!**


**Heartbeat** is a deprected cluster messaging layer that was historically used with [Pacemaker](https://wiki.gentoo.org/wiki/Pacemaker). Although it is available in [portage](https://wiki.gentoo.org/wiki/Portage), today [Corosync](https://wiki.gentoo.org/wiki/Corosync) is the preferred messaging layer and Heartbeat is not recommended for new deployments.
