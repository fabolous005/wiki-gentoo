# Konversation

From Gentoo Wiki

[Jump to:navigation](https://wiki.gentoo.org#mw-head)

[Jump to:search](https://wiki.gentoo.org#searchInput)

Konversation is a user-friendly Internet Relay Chat client. It is built on Qt and KDE Frameworks.

## Installation

### USE flags


| [+crypt](https://packages.gentoo.org/useflags/+crypt) | Add support for encryption -- using mcrypt or gpg where applicable | 
| [+handbook](https://packages.gentoo.org/useflags/+handbook) | Enable handbooks generation for packages by KDE | 
| [debug](https://packages.gentoo.org/useflags/debug) | Enable extra debug codepaths, like asserts and extra output. If you want to get meaningful backtraces see https://wiki.gentoo.org/wiki/Project:Quality\_Assurance/Backtraces | 

### Emerge

Emerge Konversation using the following command:

`root #``emerge --ask net-irc/konversation`
